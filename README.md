# Antesala

> Explora el hotel antes de llegar.

Antesala es una plataforma para que el huésped explore un hotel antes de reservar: edificio 3D → piso → unidad → espacio en 360° → reserva.

**Estado:** Fase 0, demo de venta con el hotel ficticio *Niebla Alta*.
